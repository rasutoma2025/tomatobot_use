# 🤖 tomatobot (トマトボット)

> 高機能・多機能なDiscordサーバー管理 & コミュニティ活性化Bot  
> 荒らし対策、自動プライベートVC、絵文字認証、リアルタイム地震速報、グローバルチャット、レベリング機能などをオールインワンで提供します。

---

## 🌟 主な機能

### 🛡️ 荒らし対策 & トラップチャンネル (`/antitroll`, `/trap`)
- **スパム・過剰メンション・招待リンク検知**: 設定した条件を超えた投稿を自動削除＆タイムアウト。
- **荒らしBot自動処理**: 悪質なBotを自動BAN。ユーザーインストール型Botの場合は実行者を30日タイムアウト。
- **クロスサーバー警告**: 他のサーバーで違反歴のあるユーザーが参加した際にログチャンネルに自動警告。
- **トラップチャンネル**: 誤って書き込んだユーザーを自動処罰（タイムアウト / キック / BAN）する罠チャンネルを簡単に作成可能。

### 🔒 プライベートVC & チケット機能 (`/setprivatevc`, `/ticket`)
- **自動プライベートVC**: 特定のトリガーVCに入るだけで自分専用のVCを自動作成・移動。
- **VCアクセス権管理**: `/vcinvite` / `/vckick` で指定メンバーを簡単に招待・追い出し。
- **チケットツール**: 問い合わせやサポート用の個別の非公開チャンネルをボタン一つで作成できるパネルを設置。

### 🔐 認証パネル & グローバルチャット (`/setverify`, `/setglobalchat`)
- **ボタン認証パネル**: ボタンを押したユーザーに指定のロール（「認証済み」など）を自動付与。
- **グローバルチャット**: 他のサーバーのグローバルチャット参加者とリアルタイムで会話可能。

### 🚨 リアルタイム地震速報 & 投票 (`/earthquake`, `/poll`)
- **P2P地震情報連携**: 震度指定（震度1〜6弱以上）や通知種別（地震情報・津波予報・緊急地震速報）ごとに細かく通知設定可能。
- **高機能投票ツール**: 最大20個の選択肢に対応。制限時間終了時に全自動で集計＆結果Embed発表。

### 👥 サーバーメンバー数VCカウント (`/membercount`)
- **リアルタイム人数表示**: Botを除いた人間のメンバー数だけを特定のボイスチャンネル名（例: `👥 メンバー数: 15名`）に自動更新・常時表示。接続権限の自動OFF保護付き。

### ✨ レベリング機能 (`/level`, `/setlevel`)
- メッセージ送信でXPを獲得。ランク確認ゲージカードやサーバー内ランキング上位10名の表示に対応。

### 🛠️ モデレーション & 一般ツール
- **`/check_warnings`**: サーバー内に違反・警告履歴があるユーザーを検索（管理者限定）。
- **`/delmes`**: メッセージを一括削除。
- **`/ban` / `/timeout`**: ユーザーID直接指定による柔軟な処分。
- **`/userinfo` / `/serverinfo`**: プロフィールバッジ・バナー画像・サーバー参加順など詳細情報の表示。
- **`/top`**: チャンネル内の「一番最初の古いメッセージ」へジャンプ。

## 📖 コマンド一覧

| コマンド | 説明 | 権限 |
|---|---|---|
| `/help` | Botの使い方・ガイドを表示します | 全員 |
| `/antitroll` | 荒らし対策の管理コントロールパネルを開きます | サーバー管理者 |
| `/trap create` | トラップチャンネルを作成・設定します | サーバー管理者 |
| `/trap delete` | トラップチャンネル設定を削除します | サーバー管理者 |
| `/setprivatevc` | プライベートVC自動作成トリガーを設定します | サーバー管理者 |
| `/vcinvite` | 自分のプライベートVCにメンバーを招待します | 全員 (VC所有者) |
| `/vckick` | 自分のプライベートVCからメンバーを追い出します | 全員 (VC所有者) |
| `/ticket setup` | お問い合わせチケット作成パネルを設置します | サーバー管理者 |
| `/setverify` | 絵文字・ボタン認証パネルを設置します | サーバー管理者 |
| `/setglobalchat` | グローバルチャットチャンネルを設定します | サーバー管理者 |
| `/join_global` | グローバルチャット参加ロールを取得します | 全員 |
| `/earthquake` | 地震通知の設定パネルを開きます | サーバー管理者 |
| `/poll` | タイマー付きの投票を作成します | 全員 |
| `/membercount` | VCに人間メンバー数をリアルタイム表示します | サーバー管理者 |
| `/level action:rank` | レベルと現在のXP・進捗を確認します | 全員 |
| `/level action:leaderboard` | サーバー内のレベルランキング上位10名を表示します | 全員 |
| `/check_warnings` | サーバー内の警告履歴持ちユーザーを検索します | サーバー管理者 |
| `/delmes` | メッセージをまとめて一括削除します | メッセージ管理権限 |
| `/ban` | 指定IDのユーザーをBANします | メンバーBAN権限 |
| `/timeout` | メンバーをタイムアウトします | メンバータイムアウト権限 |
| `/userinfo` | ユーザーの詳細情報（バナー・参加状況等）を表示します | 全員 |
| `/serverinfo` | サーバーの基本情報を表示します | 全員 |
| `/top` | チャンネルの一番最初の古いメッセージへ案内します | 全員 |
| `/ping` | Botの応答速度（レイテンシ）を測定します | 全員 |
